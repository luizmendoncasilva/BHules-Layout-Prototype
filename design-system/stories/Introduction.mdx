# BSystem Design System

BSystem is BHub's design system — a collection of reusable UI components built on top of [shadcn/ui](https://ui.shadcn.com/), [Radix UI](https://www.radix-ui.com/) primitives, and [Tailwind CSS v4](https://tailwindcss.com/).

All components follow the BHub visual language: consistent spacing, typography, color tokens, and interaction patterns defined in `styles.css`.

---

| **Drawer** | Slide-in panel from a screen edge |
| **Empty** | Zero-state placeholder with icon, title, description and action |
| **HoverCard** | Rich tooltip revealed on hover |
| **IconButton** | Square icon-only button with enforced accessible label |
| **Input** | Single-line text field |

| **Item** | Bordered list item with icon badge, title, description and action |

| **Label** | Accessible form field label |
